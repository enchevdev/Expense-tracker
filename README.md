# ExpenseTracker

A simple console application built with C# for tracking personal expenses.

## Features

* Add expenses with a description, amount, and category
* View all added expenses
* Calculate the total amount of expenses
* Menu-based navigation
* Input validation for menu choices and expense amounts
* Continue adding expenses until the user chooses to exit

## Technologies

* C#
* .NET
* Object-Oriented Programming (OOP)
* Lists
* Classes and objects
* Loops and foreach
* Switch statements
* Exception handling with try/catch

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Build the project.
4. Run the application.
5. Use the menu to add and view expenses.
